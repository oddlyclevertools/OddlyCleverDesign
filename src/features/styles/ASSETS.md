# Styles feature: assets

- **Colour palettes and font pairings** (`palettes.js`): written for this project. Font pairings only use the bundled @fontsource fonts (SIL OFL 1.1).
- **Oddly Clever brand colours** (`#0d0a10`, `#f3ead8`, `#ff2e7e`, `#ffc83d`, `#8fe3ff`, `#16121b`) and the **Oddly Clever wordmark** drawn in code by `oddlyWordmark()` in `brand.js`: the user's own brand, all rights reserved. Not CC0 and not GPL.
- No images, icons or fonts are shipped by this feature. Uploaded fonts and logos stay in the user's browser (IndexedDB `oddlyclever-brand`); the user is responsible for their licences.
